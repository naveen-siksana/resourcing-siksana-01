# Source Code Directory

This directory contains all the source code for the Resourcing Financials Management System.

## Structure

- **api/** - API layer including routes, controllers, and middleware
- **models/** - Data models for financials, resourcing, and shared entities
- **services/** - Business logic services for various domains
- **utils/** - Utility functions including validators, formatters, and helpers
- **database/** - Database-related code including migrations, seeds, and queries
- **modules/** - Feature modules organized by domain
- **integrations/** - Third-party system integrations

## Modules Overview

### Financials
Core financial management features including budgets, invoices, expenses, payroll, reports, and forecasting.

### Resourcing
Resource management features including employees, projects, allocations, timesheets, skills, and departments.

### Analytics
Data analysis and reporting features including dashboards, metrics, and KPIs.

### Auth
Authentication and authorization features including user management and role-based access control.
