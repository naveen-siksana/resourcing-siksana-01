# Documentation

This directory contains comprehensive documentation for the Resourcing Financials Management System.

## Contents

### API Documentation (`api/`)
- API endpoint specifications
- Request/response formats
- Authentication requirements
- API usage examples
- Separate documentation for financials and resourcing modules

### Architecture (`architecture/`)
- System architecture diagrams
- Component interaction diagrams
- Data flow diagrams
- Architecture decision records (ADRs)
- Database schema documentation

### Setup (`setup/`)
- Installation instructions
- Configuration guide
- Development environment setup
- Deployment procedures
- Troubleshooting guide

### User Guides (`user-guides/`)
- End-user documentation
- Feature walkthroughs
- Best practices
- FAQ
- Tutorial videos/screenshots

## Contributing to Documentation

When adding new features or making changes:
1. Update relevant API documentation
2. Update architecture diagrams if needed
3. Add or update user guides
4. Keep documentation in sync with code changes
